# Dokumentationshistorie

Dieser Bereich bewahrt abgeschlossene Pläne, frühere Anforderungsversionen, Abnahmen und Releaseevidenz. Sein Inhalt erklärt, wie der heutige Stand entstanden ist, ist aber **nicht normativ**.

- [`releases.md`](releases.md) gibt den kompakten Releaseverlauf wieder.
- `releases/<version>/` enthält erhaltene Spezifikationen, Implementierungspläne und Abnahmen eines Releases.
- [`increments/`](increments/) enthält abgeschlossene Inkrement- und Paketpläne.
- [`legacy/`](legacy/) enthält abgelöste Grund-, Architektur-, Entwicklungs- und Anforderungsdokumente.

Für aktuelle Aussagen gelten [`../product/`](../product/overview.md), [`../architecture/`](../architecture/overview.md), [`../adr/`](../adr/README.md), [`../development/`](../development/setup.md) und [`../operations/`](../operations/README.md).

Historische interne Links können auf die damalige Struktur verweisen. Sie sind Beleg ihres Stands, keine Empfehlung für aktuelle Arbeit.
