# Themenzuordnung für allgemeine Ausreden

Dieses Dokument weist den 144 allgemeinen Ausreden die endgültigen `ExcuseTopic`-Werte für den produktiven Katalog zu. Die Zuordnung folgt der Hauptprämisse des Textes, nicht allein seinem Stil.

Zulässige Themen für allgemeine Texte:

- `GENERAL`
- `TECHNICAL_FAILURE`
- `LONG_TERM_PLAN`
- `RESPONSIBILITY`
- `GRID_CONFLICT`

Die im ersten Qualitätsdurchgang definierten Textersetzungen ändern die hier festgelegten IDs nicht.

## Katalogregeln

Für alle 144 Einträge gelten weiterhin:

```text
games: [GRIDWORDS, QUADWORDS]
specificity: 0
weight: 100
requiresAll: []
excludesAny: []
selectable: true
```

Die Zuordnung darf später nur geändert werden, wenn sich die Hauptprämisse des Textes redaktionell ändert. Eine bloße Formulierungskorrektur ändert den Topic-Snapshot nicht automatisch.
