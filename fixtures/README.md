# Parser-Fixtures

Alle mit `synthetic-` benannten Inhalte sind repräsentative, künstliche Share-Nachrichten für dieses Parser-Inkrement. Das QuadWords-Format `X/9` beruht auf einem bestätigten Share. Das GridWords-Format `X/6` bleibt bis zu einem echten Nutzer-Share eine ausdrücklich dokumentierte Annahme.
